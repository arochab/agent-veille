# The Wire: project intelligence

Reference inspected on 1 October 2026: Linear (https://linear.app/) and its Refero analysis (https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1). Reference screenshots are in the delivery folder, not redistributed in the product.

## Direction

Borrow Linear's direct product statement, generous type scale, precise neutral surfaces and real product demonstration. Do not copy its logo, screenshots, language or components. The Wire's distinctive object is the visible connection between a research source, a project constraint and a proposed action.

Palette: canvas #090b0e, surface #12151a, raised #1b1f27, rule #30353f, text #f5f6f8, secondary #a9b0bc, functional blue #a9c4ff. Source, project and action form a real sequence; no decorative metrics. The final action uses a light surface to mark the decision point.

Typography: Arial/Helvetica system sans, 64px regular-tight display, 30px section heading, 18px body, 14px UI. Content left aligned in a 1240px frame; two-line purpose statement, then an interactive source-to-action brief. On mobile the same sequence reads vertically without compressed desktop panels.

## Review against the brief

The rejected dashboard showed tasks without explaining why the product existed. The new first screen names an AI research assistant and shows its input and output. Real documentation links ground three prewritten examples; project contexts and recommendations are illustrative, not a live agent run. One button opens the full workspace. Both English and French carry the same meaning.

The workspace uses the same type, surfaces, buttons and evidence-to-action order. Preserve working local notes, checklists, search, project filtering, archive and export. Do not modify the private Python engine or expose personal project data.
